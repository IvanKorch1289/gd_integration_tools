### 1.2 P4.19 Aggregator — REAL BUG (cycle 22, `308683c9`)

**Bug class**: silent data loss. Docstring обещал «выдаёт агрегированный результат по
достижении `batch_size` или `timeout`», но `_flush_expired` молча drop'ал expired buffers
без инкремента счётчика. Существующий тест `test_aggregator_flush_expired` закреплял баг.

**Fix** (minimal, 47 LOC production + 62 LOC test):
- `_flush_expired` → `_evict_expired` (имя = поведение).
- `evicted_batches` counter + property для observability (timeout + max_buffer head-drop
  + `_MAX_CORRELATION_KEYS` overflow).
- Docstring синхронизирован: «timeout — eviction (memory protection), не flush».
- Тест переписан: rename + assertions на counter + buffer state.

**Strict-timeout semantics (partial-emit)** — **deferred** в `SlidingWindowAggregator`
(planned S176, требует ADR).

**Verify**: `pytest tests/unit/dsl/engine/processors/eip/test_flow_control.py` → 27 passed.

**Impact**: production-grade observability. Ненулевой `evicted_batches` в метриках =
сигнал «были потерянные батчи, увеличь timeout или batch_size».

### 1.5 W-1 DSL principal propagation (cycle 24, `cfdcb971` + `b71e5442`)

**Bug class**: silent auth context loss. DSL-routed операции через
`DispatchActionProcessor` теряли `principal`/`permissions`. `ActionCommandSchema`
создавался без meta-principal (только `source`/`correlation_id` через `default_factory`).

**Fix**: явно конструировать `meta=ActionCommandMetaSchema(principal=..., permissions=...)`.

**Два коммита** (near-duplicate, см. § 4.1):

объёмом тестов. См. § 4.1.

## 2. Lessons learned

### 2.1 Duplicate commit (cycle 24, `cfdcb971` + `b71e5442`) — race condition

**Timeline**: 14:03 → 14:07, 4 минуты между коммитами.

**Root cause**: **parallel agents** работали над одним W-1 issue одновременно.
- Другой agent сделал `cfdcb971` (14:03) — 26 LOC fix + 119 LOC test.
- Мой agent сделал `b71e5442` (14:07) — 8 LOC fix + 4 LOC test (3 vs 26 LOC production diff).

**Diff between the two commits** (semantically identical, only style differs):

```python
# cfdcb971 (parallel agent) — 26 LOC production diff
meta=ActionCommandMetaSchema(
    principal=context.principal,
    permissions=list(context.permissions),
)

# b71e5442 (mine) — 8 LOC production diff (only trailing comma style)
meta=ActionCommandMetaSchema(
    principal=context.principal, permissions=list(context.permissions)
)
```

**Lessons**:
1. **Coordinate** перед WAVE-work: declare issue ownership в shared queue.
2. **Git pull + rebase** перед каждым фиксом в multi-agent setup.
3. **Locking** — overkill для async agent loops; достаточно issue tracking.
4. **Acceptable cost**: 1 duplicate commit на 6 cycles = 17% (acceptable).
5. **Mine был избыточен** — мог бы обнаружить `cfdcb971` через `git log` после своего
   `git pull`. **Process improvement**: `git pull --rebase` ПЕРЕД `git commit`.
