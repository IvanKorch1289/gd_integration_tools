# Baseline рассинхронизации YAML-конфига и моделей настроек (Wave 13 Q16).
# Формат: <kind>:<profile>:<group>:<name>  # owner=<team> | reason=<note>
# Для orphan-группа формат короче: <kind>:<profile>:<section>
# kind ∈ {orphan-group, orphan-key, missing-non-secret, missing-secret}.
# Блокирующий scope гейта по умолчанию — orphan-класс
# (orphan-group / orphan-key): опечатка в YAML-ключе = тихая потеря
# настройки. Scope 'missing' блокирует missing-secret (секрет не
# документирован в .env.example) — ADR-0373. missing-non-secret
# (поле не задано в YAML) остаётся неблокирующим.
# Каждая запись — известный долг; гейт падает только на НОВЫХ
# расхождениях (не из этого списка).
