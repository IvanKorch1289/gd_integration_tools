## 🐛 Real bugs found via regression tests (per Ponytail "boring over clever")

### NEW-12: gRPC subclass methods patch incomplete
- **Symptom**: `DownloadFile`/`UploadFile` (async generator/coroutine) MISSING `request_streaming`
- **Root cause**: Hardcoded list of method names in `_patch_rpc_methods` subclass loop didn't include streaming methods
- **Fix**: Use `dir(_cls)` to iterate ALL callable methods instead of hardcoded list
- **Status**: 50% fix (sync methods done, async issues documented as M7)

### NEW-13: FileStreamGRPCServicer import broken
- **Symptom**: `globals()["FileStreamGRPCServicer"]` → KeyError (class in submodule, not `__init__.py`)
- **Root cause**: Patch used `globals()` lookup which only returns names from current module
- **Fix**: Use `importlib.import_module()` for cross-module class lookup
- **Status**: 100% fix, all 3 servicer classes now have `__getattr__` fallback
