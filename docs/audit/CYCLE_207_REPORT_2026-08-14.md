### NEW-9: Workflow worker "spec not found" — RESOLVED

- **Issue**: Worker не загружал workflow YAML specs → "spec not found" при execution
- **Root causes (2)**:
  1. Worker `_bootstrap()` не вызывал `start_workflow_runtime()`
  2. `workflow_setup.register(wf, route_id=...)` НЕ вызывал `register_spec` → `_specs[route_id]` пуст
- **Fix**:
  - `src/backend/infrastructure/workflow/worker.py`: добавлен вызов `start_workflow_runtime(_WorkerAppStub())` в `_bootstrap`
  - `src/backend/plugins/composition/workflow_setup.py`: добавлен вызов `register_spec(route_id, wf)` после `register`
  - `ops/compose/docker-compose.yml`: добавлен `FEATURE_WORKFLOW_YAML_ROUND_TRIP: ${FEATURE_WORKFLOW_YAML_ROUND_TRIP:-true}` для workers (по умолчанию true, исправляет "FeatureDisabledError")
- **Verification**:
  - 4 workflows auto-loaded на workers: `code_interpreter_loop`, `credit_assessment`, `multi_agent_supervisor`, `rag_augmented_saga`
  - `POST /api/v1/admin/workflows/trigger/credit_assessment` → 202 + **status: running** (worker picked up, no spec error!)
