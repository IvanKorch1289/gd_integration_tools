## 7. Key lessons (R12)

1. **Run `git ls-files` before counting LOC**. Untracked files ARE
   the runtime. `wc -l src/backend/core/ai/security/agent_security.py`
   is misleading when 4 sibling files exist on disk but aren't tracked.

2. **A "deferred to P1" audit claim needs periodic re-verification**.
   R9 was right to defer (security-critical, 27/30 tests broke in
   earlier attempt), but S187 completed the work without updating
   the audit. The R8 → R11 chain never noticed because they read
   the same stale git HEAD.

3. **`git status` is the ground truth for "what's in the working tree"**.
   Every audit cycle should start with `git status --short` to see
   untracked files before counting anything.

4. **Test count is only meaningful with `--collect-only` confirmation**.
   R11 said "30 tests in test_agent_security.py + 5 in
   test_facade_validate_sql.py = 35". Reality: also
   `test_agent_security_check.py` had 10 more. R12 verified by
   running `--collect-only`.
