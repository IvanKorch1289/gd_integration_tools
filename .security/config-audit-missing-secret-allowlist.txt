# Явный allowlist класса missing-secret — ADR-0403 (волна 21).
#
# Класс missing-secret: секретное поле Settings-класса не документировано
# в ``.env.example`` (ADR-0373). Гейт: ``python tools/config_audit.py
# --scope missing`` (блокирующий, подключён в CI: .github/workflows/lint.yml).
#
# Формат записи:
#   <kind>:<profile>:<group>:<name>  # owner=<team> | reason=<обоснование>
# Пример:
#   missing-secret:prod:security:SEC_SECRET_KEY  # owner=security | reason=секрет выдаётся Vault'ом
#
# Правила (проверяются гейтом, tools/config_audit.py):
# * запись действует ТОЛЬКО если в комментарии есть ``owner=`` и ``reason=``;
#   запись без них игнорируется — расхождение продолжает блокировать гейт
#   (сигнал не теряется, «тихого» исключения из гейта не существует);
# * запись относится только к классу missing-secret; orphan-класс
#   (опечатка в YAML-ключе)allowlist'ом не скрывается никогда;
# * allowlist — не место для «заглушки»: если переменную нужно
#   документировать — она добавляется в ``.env.example``.
#
# Текущее состояние: долг по классу missing-secret = 0 записей (все 51
# секретное поле Settings-классов документированы в ``.env.example``) —
# файл существует как явный baseline и как место для будущих
# обоснованных исключений (решение владельца безопасности).
