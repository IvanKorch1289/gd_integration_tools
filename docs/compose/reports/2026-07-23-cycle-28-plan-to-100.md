### Phase 3: click → typer migration

**Problem**: 2 DSL CLI files used `click` directly, despite `typer` being in pyproject.

**Fix**: Full migration of `generate.py` (5 commands + group) to typer API:
- `@click.group()` → `typer.Typer()`
- `@cli.command()` → `@app.command()`
- `click.echo()` → `typer.echo()`
- `click.argument/option` → `typer.Argument/Option`

**Files**:
- `src/backend/dsl/cli/generate.py` (fully rewritten)

**Verification**: `ast.parse` PASS; `typer>=0.12.0` is direct dep

**Impact**: dsl 72 → 74

**Note**: `debug.py` (7 commands) left on click — separate migration candidate. Both files still work; minor inconsistency.
