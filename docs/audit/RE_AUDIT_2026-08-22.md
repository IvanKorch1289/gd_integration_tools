## 2. NEW-FOUND + FIXED: 4 systemic MOCK-fallback sites

### 2.1 Background

Round 1 audit (D-AUDIT-9701) fixed only `admin_actions.list_actions`:
```python
# Round 1 fix (cycle 97):
```

- `admin_actions.get_action_spec` (line 286, before round 3)

Admin UI showed fake action specs / plugin lists → decisions on fabricated data.

| File:line | Endpoint | Was | Now |
|---|---|---|---|
| `src/backend/entrypoints/api/v1/endpoints/admin_actions.py:286` | `GET /api/v1/admin/actions/{name}/spec` | `return _mock_spec(name)` | `raise HTTPException(503, ...)` |

## 3. NEW-FOUND + FIXED: 2 datetime deprecations

### 3.1 Background

Python 3.12+ deprecates `datetime.utcnow()` (naive timezone confusion).
`datetime.now()` without `tz=` returns naive datetime — fine for internal
use but problematic for audit timestamps that need timezone clarity.

| `src/backend/services/ai/model_registry/local_fs_backend.py:206` | `datetime.now().isoformat()` (naive) | `datetime.now(UTC).isoformat()` + added UTC to import |

### 3.3 Test impact
