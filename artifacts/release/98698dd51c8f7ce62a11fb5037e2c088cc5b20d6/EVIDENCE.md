## 1. Что изменилось в этом SHA

Оба дефекта найдены **браузерной** проверкой. Ни тесты, ни `curl` без
`Accept-Encoding` их не показывали.

### 1.1 gzip рвал соединение без ответа (критично)

`GZipCompressionExcludingMiddleware` пересобирал `http.response.start` через
`MutableHeaders.items()`, который отдаёт пары `(str, str)`, а ASGI требует
`(bytes, bytes)`. Uvicorn падал:

```
uvicorn/protocols/http/httptools_impl.py:498, in send
    if HEADER_RE.search(name):
TypeError: cannot use a bytes pattern on a string-like object
```

Соединение закрывалось **без ответа**. Воспроизводится обычным curl:

| Запрос | До | После |
|---|---:|---:|
| `GET /openapi.json` + `Accept-Encoding: gzip` | **000 / 0 байт** | **200 / 58 150 байт** |
| то же без gzip | 200 / 494 406 байт | 200 / 494 406 байт |

Затрывался **любой ответ больше `minimum_size` (500 б)** для любого клиента,
предлагающего gzip, — то есть практически для всех браузеров и для любого
прокси с gzip. Ответ был не «сломан», а **отсутствовал**: ни кода, ни тела.

### 1.2 Content-Security-Policy опустошал страницы документации

`default-src 'self'` применялся ко всем ответам, включая `/docs` и `/redoc`,
которые подключают Swagger UI и ReDoc с `cdn.jsdelivr.net` и выполняют
inline-скрипты. Браузер блокировал и стили, и скрипты:

```
Loading the script 'https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/
swagger-ui-bundle.js' violates ... "default-src 'self'". Blocked.
```

Ответ — HTTP 200 с пустой страницей. Послабление ограничено путями
документации; `/openapi.json` и все API-ответы сохраняют строгую политику.
Allowlist собран с реально отдаваемых страниц, а не придуман:
`cdn.jsdelivr.net`, `fastapi.tiangolo.com`, `fonts.googleapis.com`,
`cdn.redoc.ly`, `blob:` (web-worker ReDoc). Первая версия политики забыла
`worker-src` и шрифты — консоль показывала 3 нарушения; после уточнения
нарушений **ноль**.

## 4. Swagger UI показывает 14 операций из 443 — диагностировано

### Наблюдение

- спецификация объявляет **443 операции в 92 тегах**;
- Swagger UI рендерит **14 операций в 3 секциях** (`default`, `Health`,
  `Работа с справочником видов запросов`);
- ошибок в консоли нет, баннера об ошибке нет;
- браузер получает спецификацию целиком: HTTP 200, 494 406 байт.

### Что исключено последовательно

| Гипотеза | Проверка | Итог |
|---|---|---|
| Медленный рендеринг | повторный подсчёт на 0/10/20/40/60/90/120 с | **исключено** — всегда 9 |
| Обрыв загрузки спецификации | `fetch()` из страницы: 199 КБ, 201 КБ, 400 КБ, 522 КБ | **исключено** — приходят целиком |
| Массив в `requestBody` операции | та же операция с `type: object`, без `requestBody`, без параметров | **исключено** — все четыре варианта падают |
| Бисекция по объёму | 30 / 60 / 70 / 71 / 72 / 80 / 90 / 120 / 240 / 443 операций | порог между **71 и 72** операциями |
| Порог по размеру файла | 199 952 Б рендерятся, 201 161 Б — нет | совпадает с числом операций, не является самостоятельной причиной |
| Приложение (CSP, gzip, middleware) | та же спецификация отдаётся **статическим файловым сервером без приложения и без CSP** | **воспроизводится** |

Последняя строка — решающая: дефект воспроизводится вне проекта. Значит он
не в приложении.

### Вывод

Swagger UI 5 молча прекращает рендеринг этой спецификации после ~72
операций. Ошибок нет, со временем не появляется, размер ответа не при чём,
контент конкретной операции не при чём. Это ограничение стороннего
рендерера на спецификации с большим числом операций, а не дефект сервиса.

Наш прежний вывод («рендеринг просто медленный») был неверен: 120 секунд
не помогают. И наш вывод «это может быть регрессия от правок CSP/gzip»
тоже неверен — правки подняли `/docs` с **0** операций до 14, а поломка
воспроизводится без приложения вообще.

### Практическое следствие

**`/redoc` отображает спецификацию целиком** — 429 863 символа, все группы
тегов (`Auto-Registered`, `DSL`, `admin`), которых Swagger UI не показывает.
Проверено и на статической странице ReDoc, и через приложение — результат
идентичен. То есть CSP-послабление ничего не ограничивает, а рабочим
браузерным представлением контракта является `/redoc`.

Итог браузерной проверки: **7 PASS, 1 PARTIAL, 0 FAIL**, ошибок в консоли нет.
Единственный PARTIAL — Swagger UI, с установленной причиной и рабочей
альтернативой.
