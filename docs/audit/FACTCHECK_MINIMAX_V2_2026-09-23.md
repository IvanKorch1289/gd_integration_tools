## 2. Почему у внешнего аудита вышло иначе

`requires-python = ">=3.14,<3.15"` (pyproject.toml:6). Синтаксис `except A, B:`
без скобок — **PEP 758**, принятый в Python 3.14; на Python ≤ 3.13 это
`SyntaxError: multiple exception types must be parenthesized`. Любая
компиляция/AST-обход на 3.12–3.13 даёт ровно ту картину, которую описал
внешний аудит («148 ошибок») — это норма для нецелевой версии интерпретатора,
а не дефект кода. Проект закрепил это решением:

- **ADR-0304** (docs/adr/WIKI.md): «except-кортежи без скобок каноничны
  (PEP 758); гейт перепрофилирован в fail-closed parse».
- Runtime-верификация в PROGRESS_LEDGER (2026-09-22): на 3.12.3 тесты падают
  на import; на 3.14.4 — все собираются и проходят.
- `tools/checks/check_alembic_migrations.py` и CI-шаги выполняются на
  `uv run` с 3.14 — гейты зелёные.
